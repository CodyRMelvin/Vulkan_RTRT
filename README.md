Project is built via CMake and ninja multi-config.

A series of shell scripts are provided for interfacing with it.

cmake.sh invokes CMake directly.

build.sh invokes the ninja build system. It requires one paramter detailing the build configuration (Release, Debug, or RelWithDebInfo), it is not case sensitive.

run.sh moves to the correct directory and run the program, then move back. It also takes in a parameter detailing the build configuration. Additionally, it runs build.sh prior to the program.

compileShaders.sh goes through each file in the src/shaders directory (excluding rng.glsl and shared_structs.h) and calls the provided makefile with them as a parameter, which glslandValidator to compile them.

clean.sh removes all files and directories generated by the prior shell scripts.
